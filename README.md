FUTURE_CS_02
Phishing Email Detection & Awareness System
📌 About the Project

This project was completed as part of the Future Interns Cyber Security Internship – Task 2.

The objective is to analyze phishing email and SMS samples, identify phishing indicators, classify their risk, and provide practical security awareness guidance.
🎯 Objectives

    Identify phishing indicators
    Analyze suspicious senders, links and attachments
    Identify social-engineering techniques
    Classify phishing risk levels
    Provide prevention and awareness recommendations

🔍 Cases Analyzed
Case 001 – Microsoft Password Expiration Phishing

    Attack Type: Credential Phishing / Brand Impersonation
    Risk: High
    Key Indicators: Fake branding, password-expiration theme, suspicious action button

Case 002 – Apple App Store Invoice Phishing

    Attack Type: Malicious Attachment / Brand Impersonation
    Risk: High
    Key Indicators: Suspicious sender domain, unexpected PDF attachment, fake purchase notification

Case 003 – Coinbase SMS Phishing

    Attack Type: Smishing / Brand Impersonation
    Risk: High
    Key Indicators: Suspicious link, deceptive domain character, security-related social engineering

    🔎 Analysis Approach

The phishing samples were analyzed using a structured security-analysis process:

    Reviewed the sender information and message content.
    Examined suspicious links, attachments, and branding.
    Identified social-engineering techniques and phishing indicators.
    Compared suspicious details with expected legitimate communication patterns.
    Classified each case as Safe, Suspicious, or Phishing based on the observed indicators.
    Documented the findings and recommended prevention measures.

🛡️ Key Awareness Takeaways

    Verify the sender before trusting an email or message.
    Do not click suspicious links.
    Do not open unexpected attachments.
    Be cautious of urgent or fear-based messages.
    Check domains and URLs carefully.
    Never provide passwords, OTPs, or sensitive information through suspicious requests.
    Report suspected phishing messages to the appropriate security team.

⚠️ Disclaimer

The samples used in this project are publicly available phishing examples collected for educational and security-awareness purposes. They were analyzed only for learning and defensive awareness.
